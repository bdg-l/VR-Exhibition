# VR-Exhibition
Strength to Withstand the Last Great Conflict — VR Exhibition

An immersive Virtual Reality exhibition developed in Unreal Engine, designed to guide visitors through a compelling, interactive experience exploring the strength, preparation, and perseverance needed to withstand the Last Great Conflict. Through immersive environments, interactive exhibits, and engaging visual storytelling, the project aims to educate, inspire reflection, and create a meaningful experience for every visitor.

Built collaboratively by a four-person development team using Unreal Engine, Git, and GitHub.
